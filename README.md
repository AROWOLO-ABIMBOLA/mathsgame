# Number Buddies

Fun maths for children, from counting to Primary 6: the Number Arcade (+ − × ÷ with maths legends and crowns), School Maths for Primary 1 to 6 with lessons, practice and certificates, Nigerian story questions, stickers, a Dress-up studio and voice messages from parents.

Made by **Dr. Arowolo Ayoola**.

## Put it online with GitHub Pages (about 10 minutes, no coding)

1. **Sign in** at <https://github.com/login> as **AROWOLO-ABIMBOLA**.
2. **Upload the files:** open <https://github.com/AROWOLO-ABIMBOLA/mathsgame/upload>
   (or open <https://github.com/AROWOLO-ABIMBOLA/mathsgame> and click **uploading an existing file**).
   - Drag in **everything inside this folder**: `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, `.nojekyll` and the whole `icons` folder.
   - Commit message: `Number Buddies first release`, then click **Commit changes**.
3. **Switch on GitHub Pages:** open <https://github.com/AROWOLO-ABIMBOLA/mathsgame/settings/pages>
   - **Source:** Deploy from a branch. **Branch:** `main`, folder `/ (root)`. Click **Save**.
4. **Wait 1 to 2 minutes.** Watch <https://github.com/AROWOLO-ABIMBOLA/mathsgame/actions> for a green tick, then open
   **https://arowolo-abimbola.github.io/mathsgame/**
5. **Share the link** on WhatsApp, by text or by email.

## Updating the game later
Open <https://github.com/AROWOLO-ABIMBOLA/mathsgame/upload/main>, drag in the new `index.html` (it replaces the old one) and commit. Children get the new version the next time they open the game with internet. Their progress is not affected.

## For parents: how it works

**Each child's progress is saved on the device they play on.** There are no accounts and nothing is sent to a server, so the game is private and works for children in different homes and locations, each on their own device.

- **Install it like an app.** On Android (Chrome), tap **📲 Install app** on the home screen, or the browser menu **⋮ → Add to Home screen / Install app**. On iPhone or iPad (Safari), tap the **Share** button, then **Add to Home Screen**. The game then has its own icon and works even without internet.
- **Please install it on iPhones and iPads.** Safari may clear website data if a site is not opened for 7 days. Games added to the Home Screen keep their progress.
- **Several children on one device:** tap **👪** on the home screen to switch child or add a new one. Each child keeps their own stars, crowns, stickers, outfit and voice messages.
- **Moving to a new phone or keeping a safe copy:** open the **🔒 Parent corner → Settings → 💾 Save backup**. Send the file to the new device (for example by WhatsApp or email), then on the new device use **📂 Load backup**. Voice messages are not included in backups; record them again on the new device.
- **Voice messages** need microphone permission the first time you record. They are stored only on that device.
